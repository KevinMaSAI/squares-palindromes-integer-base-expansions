# squares-palindromes-integer-base-expansions
Preprints on squares, palindromes, and integer base expansions by Qiyuan Ma (School of Artificial Intelligence, Shanghai Jiao Tong University).

1. Squares and disjoint repeats in finite windows with few palindromes — `paper1-squares-disjoint-repeats-finite-windows.pdf`, `paper1-finite-windows/`
2. Long powers and palindromes under growing integer multipliers — `paper2-powers-palindromes-growing-multipliers.pdf`, `paper2-multipliers/`
3. A rational translation bounding palindromes on the middle-third Cantor set — `paper3-rational-translation-cantor-set.pdf`, `paper3-cantor-translation/`
4. A factor-entropy threshold for palindromes after rational translation — `paper4-factor-entropy-threshold.pdf`, `paper4-entropy-threshold/`
5. Affine separation of squares and palindromes and a full-dimensional transcendental family — `paper5-affine-separation-transcendental-family.pdf`, `paper5-affine-separation/`
